Частые вопросы

Программа бесплатная?

Да, проект распространяется бесплатно. Скачивай EXE из официального GitHub Releases.

Нет. Сайт показывает информацию о проекте и профили рекомендаций. Системные действия выполняются только в отдельном приложении.

Где посмотреть код и историю обновлений?

Исходный код и все опубликованные версии доступны на GitHub проекта.
