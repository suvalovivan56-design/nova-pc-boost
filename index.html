03 / GOOD TO KNOW

Questions?
Answered.

Коротко о загрузке, безопасности и принципах NOVA PC BOOST.

NOVA бесплатная?

Да, приложение доступно бесплатно через официальный GitHub Releases. Ссылки на скачивание и исходный код находятся на этой странице.

Программа гарантирует больше FPS?

Нет. Производительность зависит от железа, драйверов, игровых сцен и настроек. NOVA помогает управлять некоторыми параметрами, но не обещает универсальный прирост.

Можно отменить внесённые изменения?

Поддерживаемые твики сохраняют исходные параметры для отката. Перед изменениями всё равно рекомендуется сохранить работу и действовать по одному пункту.

Сайт сам что-нибудь устанавливает?

Нет. Сайт показывает информацию и ссылки. Исполняемый файл скачивается отдельно из GitHub Releases; запуск и системные действия выполняются только тобой.
