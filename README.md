# NOVA PC BOOST

**Нативное приложение для Windows на C# / WPF — без Python.**

Сайт: https://suvalovivan56-design.github.io/nova-pc-boost/

## Скачать
Откройте [последний релиз](https://github.com/suvalovivan56-design/nova-pc-boost/releases/latest) и скачайте `NOVA_PC_BOOST.exe`.

## Возможности
- Тёмный Control Center с боковой навигацией.
- Игровые профили CS2, Rust и Dota 2.
- Windows-твики с подтверждением, резервным сохранением и проверкой отката.
- Диагностика Windows, процессора, доступных данных о GPU, RAM, системного диска и плана питания.
- Ручное сравнение среднего FPS и 1% low до/после с локальной историей замеров (FPS не измеряется автоматически).
- Проверка последнего релиза GitHub по запросу пользователя; приложение не скачивает и не устанавливает обновления автоматически.
- Автоматическая попытка отката при ошибке применения твика; блокировка новых изменений, если локальный файл резервных копий не читается.
- Проверка результата восстановления службы по конфигурации и состоянию.
- Локальный журнал действий и ошибок приложения.
- Мониторинг CPU, RAM и занятого места на системном диске.
- Быстрый запуск системных инструментов Windows.
- Очистка старых пользовательских временных файлов с подтверждением.

## Технологии
- C# и WPF, .NET 8.
- Самодостаточная сборка Windows x64.
- GitHub Actions автоматически собирает и публикует EXE.

## Разработка
Откройте `app/NovaPCBoost.csproj` в Visual Studio 2022 с .NET 8 SDK или выполните:

```powershell
dotnet run --project app/NovaPCBoost.csproj
```

Для публикации используйте GitHub Actions. Версия приложения задаётся в `app/NovaPCBoost.csproj`. Диагностика и ручные FPS-замеры находятся в разделе «Диагностика и FPS». Проверка обновлений доступна в разделе «Системные инструменты» и запускается только по кнопке.

## Безопасность
Твики применяются только после действия пользователя. Перед изменением настроек NOVA сохраняет исходные значения в локальном профиле пользователя и предлагает откат. Прирост FPS не гарантируется: результат зависит от оборудования, игры и текущих настроек. Если файл резервных копий повреждён или не читается, приложение блокирует новые системные изменения, чтобы не затереть существующий файл. При ошибке применения NOVA пытается вернуть исходные значения и сохраняет резервную копию, если откат не подтверждён. Перед запуском скачанного EXE проверь файл антивирусом. Изменения следует проверять на Windows 10/11; успешная сборка сама по себе не заменяет испытания на реальном компьютере.
