# NOVA PC BOOST
Бесплатный Windows gaming toolkit. Сайт: https://suvalovivan56-design.github.io/nova-pc-boost/

## Скачать EXE
После создания релиза откройте https://github.com/suvalovivan56-design/nova-pc-boost/releases/latest

## Выпустить новую версию
1. Измените код при необходимости.
2. Создайте и отправьте тег версии, например: `git tag v1.3.1 && git push origin v1.3.1`
3. GitHub Actions соберёт Windows EXE на Windows runner и прикрепит его к релизу.
Также сборку можно запустить вручную на вкладке Actions через workflow_dispatch.

## Важно
Игровые профили — рекомендации, они не применяют системные твики автоматически. Очистка временных файлов пропускает занятые/недоступные объекты. Приложение бесплатно. Перед запуском скачанных EXE проверяйте источник и файл антивирусом.
